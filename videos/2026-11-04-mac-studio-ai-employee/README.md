# Always-On Mac Starter Kit

Give your AI its own computer that never sleeps, reach it from anywhere, and keep your passwords to yourself.
From the video "I Turned My Mac Studio Into an AI Employee" by David He, NexAI Advisors.

Watch: (link added when the video is public)

| File | What it is |
|---|---|
| `SETUP.md` | The four setup steps, plus the two settings that keep the machine online |
| `FIRST-PROMPT.md` | The first prompt to give any coding agent, and three rules |
| `watcher.plist` | A launchd template that runs any script every 15 minutes |
| `AGENT-INSTRUCTIONS.md` | Give this to your AI agent: what each file is for, and how to work on the machine safely |
| `health-check.sh` | A read-only check: scheduled jobs, last runs, newest backup, sleep and update settings |

Nothing here changes a setting by itself. Read each file before you use it.
